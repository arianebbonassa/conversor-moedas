# Conversor de Moedas

Projeto desenvolvido para praticar lógica de programação com JavaScript, HTML e CSS. Permite converter valores em Reais (BRL) para Dólar, Euro, Libra e Bitcoin, atualizando dinamicamente a bandeira e o nome da moeda selecionada.

## 🚀 Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript (ES6)

## 💻 Funcionalidades
* Conversão baseada em cotações predefinidas.
* Formatação automática de valores usando a API `Intl.NumberFormat`.
* Troca dinâmica de imagens e nomes conforme a moeda escolhida.

## 🛠️ Como executar
1. Clone este repositório ou faça o download dos arquivos.
2. Abra o arquivo `index.html` no seu navegador (ou utilize a extensão *Live Server* do VS Code).
